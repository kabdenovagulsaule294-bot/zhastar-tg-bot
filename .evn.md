# Telegram-бот Молодёжного ресурсного центра

Python 3.12 и aiogram 3.x. Команда /start и Reply-кнопки «О нас», «Направления», «Контакты». Работает в личном чате; неизвестные сообщения возвращают меню.

## Запуск в облаке

1. Загрузите содержимое этой папки в проект облачного сервиса.
2. Выберите Python 3.12 и постоянный фоновый процесс (worker).
3. Команда установки: `pip install -r requirements.txt`.
4. В настройках секретов сервиса задайте `BOT_TOKEN` токеном от @BotFather.
5. Команда запуска: `python bot.py`.
6. Оставьте одну реплику и включите автоматический перезапуск при сбое.

Бот использует long polling: публичный URL и входящий HTTP-порт не нужны. Нужен исходящий HTTPS-доступ к Telegram API. Для одного токена запускайте только один процесс. Сервис должен поддерживать постоянную работу; функции с коротким временем выполнения и HTTP-only сервисы без worker не подходят. Не запускайте одновременно локальную и облачную копии с одним токеном. При запуске удаляется ранее установленный webhook, ожидающие сообщения сохраняются.

## Docker

```bash
docker build -t mrc-bot .
# BOT_TOKEN должен быть заранее задан в окружении оболочки.
docker run -d --name mrc-bot --restart unless-stopped -e BOT_TOKEN mrc-bot
```

## Локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN='ТОКЕН_ОТ_BOTFATHER'
python bot.py
```

PowerShell: активируйте `.venv\Scripts\Activate.ps1`, затем задайте `$env:BOT_TOKEN = 'ТОКЕН_ОТ_BOTFATHER'` и выполните `python bot.py`.

Код читает токен только из окружения через os.getenv("BOT_TOKEN"). Файл .env автоматически не загружается. Не помещайте действующий токен в исходники.

Документация: https://docs.aiogram.dev/en/latest/dispatcher/long_polling.html
